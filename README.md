# ProjectZebra
This is the repository for OthellogicCraft

## How it does work?
ProjectZebra is the client application for FTP Othello Server that choose specific protocol.
ProjectZebra works as Othello Client using several AI.

## How it special?
ProjectZebra has a convenient registering system.
You can add new AI into program dynamically using REGISTRY.
Also you can add new Protocol into program same as it.

## How to Use?
The project is managed under Gradle.
You can link its project and build ProjectZebra.
After that, Run ProjectZebra Class to start Othello Client.
Please be careful to run server application before the Client!
